# VERDÉ — Sustainable Kitchenware

A clean, modern and eco-friendly e-commerce website concept designed for sustainable kitchenware products.

## 🌿 About the Project

VERDÉ is a premium e-commerce website concept focused on eco-friendly kitchen products and sustainable living.

The design combines a clean editorial layout with product-focused sections, large imagery, smooth spacing and a responsive user experience.

## ✨ Features

- Responsive website design
- Modern navigation bar
- Product search interface
- Hero section
- Bestseller products
- Product cards
- New arrivals section
- Product gallery
- Customer testimonials
- Sustainability section
- Shopping cart interface
- Responsive mobile layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Unsplash Images

## 📱 Responsive Design

The website is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile

## 🎨 Design

**Style:** Minimal • Premium • Eco-friendly • Modern

**Color Direction:**  
Natural green, warm neutrals and soft white tones.
